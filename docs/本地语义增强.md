# 本地语义增强：可选安装与使用

v2.1.1 的普通模式可独立检索、推荐和反馈迭代，不需要第三方 Python 包、ChatGPT 账号或 API Key。语义增强是可选功能：Sentence Transformers 在自己的电脑上对研究问题和论文标题／摘要编码，辅助候选排序。它不在云端理解你的评分备注，也不会自动训练模型参数。

## 安装到独立 Python 环境

在解压后的程序根目录执行。建议独立环境，避免更改原有科研软件依赖。首次安装需要网络，计算依赖及模型下载量明显大于普通源码包；可以先使用普通模式。

Linux/macOS：

```bash
python3 -m venv .venv-semantic
source .venv-semantic/bin/activate
python -m pip install --upgrade pip
python -m pip install '.[semantic]'
python -m lite_recommender --workspace ../LiteRecommenderData serve --open
```

Windows PowerShell：

```powershell
py -m venv .venv-semantic
.\.venv-semantic\Scripts\python.exe -m pip install --upgrade pip
.\.venv-semantic\Scripts\python.exe -m pip install ".[semantic]"
.\.venv-semantic\Scripts\python.exe -m lite_recommender --workspace ..\LiteRecommenderData serve --open
```

使用原来的实际数据路径替换示例路径。停止旧服务后再启动，避免端口冲突。安装依赖的 Python 和运行服务的 Python 必须是同一个环境；在其他环境安装后，仅刷新网页不会使旧服务获得新依赖。Windows 可直接使用环境中的 `python.exe`，不需要改变 PowerShell 执行策略。

## 下载、启用与离线使用

1. 打开「设置与定时运行」，检查本地语义增强状态。缺少依赖时，普通模式仍可用。
2. 点击「下载本地语义模型」。只有明确点击或执行模型准备命令才下载；普通检索不自动下载模型或安装依赖。
3. 本程序仅支持固定版本的 E5 small 模型；不接受任意模型路径或远程代码。默认下载 `intfloat/multilingual-e5-small` 到个人数据目录中的 `_shared/models/multilingual-e5-small`。可配置模型目录，但必须在该数据目录的 `_shared/models` 下。
4. 下载完成后勾选「使用 Sentence Transformers 辅助排序」，保存设置，先做真实预览。默认语义排序权重0.25，可调整为0～0.5。
5. 模型完整下载后，语义计算可离线执行；真实文献检索、Elsevier 接口及新 PDF 获取仍需联网。

如果依赖缺失、模型未准备好或加载失败，检索会保留普通规则结果并给出状态或警告，不编造语义分数。普通模式也支持反馈迭代。

模型目录与程序代码分开保存，升级继续使用原数据目录。源码分享包不包含 PyTorch、模型权重或维护者的缓存；每位使用者自行安装与下载。普通私有备份不应被视为完整模型副本，保留模型时可另外复制 `_shared/models`。

命令行也可显式准备模型（使用同一个已安装依赖的 Python）：

```bash
python -m lite_recommender --workspace ../LiteRecommenderData semantic-setup
```

## 如何理解语义结果

输入是研究问题与候选论文题名、摘要。E5 使用 `query:` 和 `passage:` 前缀，生成归一化向量并计算相似度；长文本受模型长度限制，会截断。完整论文需要另外分段分析，本功能不读取或总结整个 PDF。

语义相似度补充词面匹配，不能当作相关概率、文献质量、创新性或科研产出的评分。没有摘要的候选仍留待核验；语义模型不能凭标题补写缺失摘要。

研究对象、核心概念和排除条件仍需核对。尤其在材料、医学等专业方向，应比较相同候选在普通模式和增强模式下的排序、前10篇的人工相关性及漏检情况，再决定权重。语义模型不能挽救根本未被数据源召回的论文。

## 反馈与隐私

模型推理在本机 CPU 上执行；题名、摘要、问题和个人反馈不发送给 ChatGPT。模型首次下载连接模型仓库，会暴露通常的网络请求信息；真实检索词仍发送给所选文献数据源。官方 Elsevier 凭据单独由服务环境配置。

反馈迭代仍是本地偏好权重更新，不自动微调 Sentence Transformers 参数。有至少3篇有效兴趣评分、其中至少2篇摘要完整的4～5星论文时，也会用这些高评分论文的平均向量以20%比例调整研究问题向量；不编码自由备注、“没时间”或仅访问困难的反馈。自由文字备注保留，但不作为大模型指令执行。旧批次和评分快照不因启用模型而重写。
