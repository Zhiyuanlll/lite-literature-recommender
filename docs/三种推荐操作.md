# 三种推荐操作

名称分别为“下周预览”“重选本周推荐”“评分后加速迭代”。

下周预览读取最新已保存反馈，生成核心＋相关目标数量的未展示论文，仅阅读，不提交评分，也不写入持久偏好策略。当前日期仍是实际日期，未来发表的论文不会被模拟生成。

重选本周推荐适用于不满意整轮结果。使用当前方向配置和已生效的反馈偏好，主动刷新来源并换一批未展示论文。原清单及评分留存，周历史位置替换为新清单。整轮不满意不会自动变成每篇的低分。

评分后加速迭代要求所选方向当前可评分清单的每篇都已经保存1–5星评分。读取这些反馈更新偏好，推荐未展示论文。新清单可以继续评分，同一个已评分基准批次不会重复产生多次加速迭代。配置变更后应先重选本周推荐，在新配置清单中评分。

所有展示批次（包括只读预览）参与该方向的论文去重。因此新推荐会扩展检索寻找未展示论文，不按重复内容凑数。核心默认5、相关默认15，两组可分别设置。论文不足时报告缺口；自动扩展有时间和分页边界，不保证全库遍历。缺摘要但标题相关的论文也可进入相关组，明确标注“仅标题”。

每周自动运行按配置时区的ISO周执行一次；同周已有重选清单时不再另发一轮。历史界面显示当前可评分清单、最新只读预览及每周当前清单，不显示每次内部检索页。原始运行审计记录不会删除。

CLI可指定`run --action weekly|preview_next|reselect|accelerate`；加速迭代可指定`--base-run-id`。网页隐藏内部分页操作，统一显示候选与筛选原因。兼容旧CLI批次参数以读取原数据，不建议新流程使用旧手动分页命令。

左侧勾选决定执行操作的方向；阅读清单的“筛选方向”仅改变显示。未有当前清单的方向需要先重选生成推荐，再评分与加速迭代。
