# 分享、发布与隐私

## 发布的是通用源码

Lite Recommender v2 可按 MIT 许可证公开发布、修改和再分发，保留 LICENSE 和 NOTICE。第一次使用的研究方向由接收者创建；HEA、DDD、医学影像、机器人文件只作填写示例，默认不开启。

可发布的交付是供各人在自己电脑运行的源码包。本地网页没有远程多人账户或公网认证部署方案，默认只监听 `127.0.0.1`。不要把本地端口直接转发到公网来提供共享服务。

普通模式无第三方运行依赖，Python 3.10+。可选本地语义增强依赖 Sentence Transformers 及其计算依赖；模型不会收入源码 ZIP。`pyproject.toml` 支持项目元数据；本发行首选源码 ZIP，无需构建 wheel。可选 Python wheel 构建依赖 setuptools，不属于运行时需求。包内自带示例，因此 wheel 安装后可使用 `init --examples`；详细文档、启动脚本和完整测试仍在源码ZIP中。

wheel 同时包含隔离验证用例，安装后可以直接运行 `python -m lite_recommender verify`。源码 ZIP 保留完整文档与可编辑的 tests/；源码和 wheel 的验证都需要允许本机回环端口，不会联网抓取论文。

## 标准构建

从代码目录执行：

```bash
python3 -m lite_recommender verify
python3 scripts/build_release.py
```

输出：

```text
dist/
├── Lite_Recommender_v2.1.0.zip
├── Lite_Recommender_v2.1.0.zip.sha256
└── Lite_Recommender_v2.1.0.MANIFEST.json
```

文件清单也包含在 ZIP 内的 `MANIFEST.json`。构建器不递归压缩整个工程，而只收录：

- 包内 Python、网页静态资源。
- tests 内 Python 与合成 JSON 固件。
- docs 内 Markdown、examples 内通用 JSON/Markdown。
- scripts 中受支持的启动、构建、校验脚本。
- README、许可证、NOTICE、CHANGELOG、pyproject、gitignore。

workspace、data、runs、backups、PDF、数据库、缓存、日志、虚拟环境、Git 元数据和符号链接不入包。发现典型内嵌私钥或 token 时构建器拒绝发布。白名单和模式检查不能发现所有人为写进源码或文档的私人信息；维护者新增样例／测试固件时仍应人工审阅。

同样源码产生固定 ZIP 文件时间戳和一致字节内容，便于校验。更新代码后应更新版本和 changelog，再重新构建，避免同版本不同内容。

## 收件人验证

Linux 在 ZIP 所在目录执行：

```bash
sha256sum -c Lite_Recommender_v2.1.0.zip.sha256
```

Windows PowerShell：

```powershell
Get-FileHash .\Lite_Recommender_v2.1.0.zip -Algorithm SHA256
```

比对发布者提供的完整 SHA-256 后解压。在解压根目录运行：

```bash
python3 scripts/verify_release.py
python3 -m lite_recommender verify
```

第一步验证源代码是否与包内清单一致；第二步运行离线软件测试。校验和用于完整性核对，不是发布者身份签名；应通过可信发布地址取得校验值。

启动程序会创建个人 workspace，它不在源代码清单内。运行后重新校验仍只比较源码文件；不能据此判断个人数据库完整性。

## 哪些数据保存在本地

| 数据 | 默认位置 | 分享建议 |
|---|---|---|
| 问题、关键词与方向配置 | 方向 profile、数据库、topics.json | 可能暴露研究计划，按个人意愿 |
| 星级、理由、标签、阅读状态 | `_shared/library.sqlite` | 属于个人数据，不公开 |
| 检索元数据缓存 | `_shared/cache/` | 不在源码包，不保证可再分发 |
| 推荐快照、周报、导出 | `_shared/runs/` 与方向 runs | 审阅问题和备注后再分享 |
| 个人备份 | `_shared/backups/` | 含真实个人数据，不公开 |
| 密钥和邮箱 | 可选环境变量 | 不写入源码、配置、日志或分享包 |
| 本地语义模型与向量缓存 | `_shared/models/`、`_shared/semantic_cache/` | 不收入源码发行包；向量缓存按个人数据处理 |

真实检索会将搜索词发送给 Crossref、OpenAlex、arXiv，并受各来源条款与限流约束；对未公开研究计划敏感时应先调整关键词。程序没有账户登录、广告或使用情况分析端点，不主动将评分或备注发送给这些来源。可选语义模型首次准备连接模型仓库；推理在本机CPU上完成，不把研究问题、摘要或反馈发送给云端大模型。Elsevier接口凭据仅由服务环境读取。

元数据、论文全文、期刊图表与用户自己的研究材料可能受不同许可限制。MIT 仅适用于本软件代码，不授予再发布检索内容或全文的额外权限。应用可按用户命令保存公开PDF，不自动登录浏览器账户、不发送浏览器cookie；可选官方接口只向 Elsevier 发送使用者配置的 API 凭据；文件不纳入源码分享包和默认备份。

## 发布验收建议

在临时目录解压发行包，校验清单、运行 verify、创建空 workspace、加载通用例子、运行 demo、保存并改写反馈、导出、备份，再关闭服务。另记录真实联网检索的来源状态及论文链接。

源码、离线流程、真实 API、Linux 登录服务、Windows 登录任务分别记录结果。未在某平台实际注册任务时，应在版本说明中标为未实机验证，而不是把“脚本已包含”写成“调度已全面通过”。

新接收者的 workspace 应为空，示例未启用，计划关闭。检查包中不得出现发布者的历史评分、个人题名、私人问题、备份、PDF 或真实凭据。
