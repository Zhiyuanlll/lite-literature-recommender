# 下载、导出与导入论文 PDF

选择正式推荐或真实预览批次 → “导出” → “下载论文 PDF（ZIP）”。无需先评分，下载不占周配额，不改变评分。先复用已有文件，尝试启用的官方 API 和公开 PDF；未获取时进入专用机构浏览器，首次选择学校并登录。程序运行期间复用会话，退出后清除。机构无法取得时自动按 DOI 查询 Sci-Hub，两条浏览器会话隔离，无需配置链接。详见[机构访问](学校访问与PDF导入.md)。

PDF 下载按钮及嵌入的 PDF 会自动识别；登录和验证需在浏览器完成，再回本地页面点“继续下载”。机构没有权限时可点“机构无法获取”，外部查询无结果时可跳过。每次人工等待最多5分钟。ZIP包含成功获取的PDF及逐篇报告，全部失败不生成空ZIP。演示论文没有PDF。单篇保存上限25 MiB；预印本与正式版可能不同，请核对版本。

文件按论文ID命名，ZIP中download_report.json提供题名与文件名对应关系。本机副本保存在workspace/_shared/pdfs/；下载后的ZIP由浏览器选择保存位置。已有文件复用。源码分享包不包含下载的论文或个人数据。

# 可选公开 PDF 保存

先在真实推荐批次中评分，再从命令行执行：

```bash
python3 -m lite_recommender --workspace '/path/to/your/workspace' \
  download --run-id RUN_ID --min-rating 4
```

用网页中真实批次的 ID 替换 `RUN_ID`。`--min-rating` 可以设1–5，默认4。选择条件是该批次对应方向及 profile 版本的最新评分达到门槛，或者阅读状态为 `cited`。没有评分且未引用的文章不自动下载，演示文章永远跳过。

公共下载从已保存的论文快照中读取 `pdf_url` 和版本列表的 `pdf_url`；启用的 Elsevier 官方接口另外尝试授权 PDF，失败后回退公共链接。网页上的原文／PDF外链可用于自己查看；网页现已提供批量下载按钮。

文件保存至：

```text
workspace/_shared/pdfs/PAPER_ID.pdf
workspace/_shared/runs/RUN_ID/download_report.json
```

同一论文跨方向只需保存一份；文件名优先使用当前统一的 canonical paper ID，历史预印本快照不会仅因旧身份再另存一份。重复调用发现已有非空 `%PDF-` 文件时跳过。检查PDF头是一项下载完整性筛选，不等于PDF结构全部通过验证，也不等于已完成全文阅读。

只接受公开HTTPS链接，主机及每次重定向均核验公网IP；拒绝本机、私网、保留地址和包含账户凭据的链接。TLS保持域名验证，连接固定到已核验地址。请求不带账号cookie、Authorization或机构会话，不改写登录限制。遇到登录页、403、非PDF响应或缺少直链会记录结果，继续下一篇。

单文件大小上限25 MiB，连接／读取超时15秒。使用临时文件，验证通过后原子保存；失败不留下半份PDF，也不覆盖原有文件。报告保留下载、已有、无链接、失败及跳过状态；签名查询参数不复制到报告中。

下载不会增加周推荐数量，不修改评分、阅读状态、基础分或推荐批次状态。失败仅在 `download_report.json` 中记录，不能把下载失败解释为文献无关。

默认个人备份不包含 `_shared/pdfs/`，需要保留文件时请另行备份。源码发布ZIP也排除PDF。公开可访问不改变原文版权及许可，分享全文应按其许可执行。需要机构账户的文章可自行从原始链接按既有权限获取，再另行保存；本工具不自动化账户登录。

本模块的回归测试使用HTTP与DNS模拟响应及合成PDF头，不下载真实论文全文。正式使用仍需查看真实链接可用性。


## Fake-IP 网络适配与失败报告（v2.0.3）

系统DNS若仅在198.18.0.0/15范围返回Fake-IP地址，程序改用Cloudflare的DNS-over-HTTPS查询出版商真实公网IP，再固定连接该IP并校验原域名TLS证书。不会直接连接Fake-IP地址，不允许普通私网、回环或保留地址。公网DNS不可用时停止并显示原因，不关闭证书或地址检查。此回退仅向Cloudflare发送待下载链接的主机名，不发送论文路径、研究方向、评分或账户信息。公网正常解析不使用该回退。

批次下载完成后页面持久显示每篇论文的结果与原因，切换历史批次也可查看。全部未获取到PDF时不生成或自动下载空ZIP；部分成功时ZIP只包含已获取PDF及报告，报告保留失败原因。PDF获取失败不等于文章需要付费，也不会影响推荐反馈。HTTP403等出版商访问限制仍可能发生，可从原文页面按自己的访问权限获取。

## 官方接口与本地导入

Elsevier 官方接口、学校资源入口、可选 Sci-Hub 外部 DOI 链接及本地导入见[学校访问与PDF导入](学校访问与PDF导入.md)。官方接口仅向获准域名发送环境中配置的凭据；学校与外部入口不自动抓取全文或摘要。

新版候选面板中的待核验论文也可导入 PDF。提取摘要须由使用者核对确认后才用于后续评分；旧批次保持原样。待核验论文不会仅因保存 PDF 而消耗正式推荐配额。
