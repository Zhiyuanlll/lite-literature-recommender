# 使用说明（v2.2.0）

按README中的Windows/macOS/Linux脚本启动，浏览器访问`http://127.0.0.1:8765/`。需要Python3.10+；普通模式无需安装第三方运行依赖。代码和个人数据工作区分开保存，升级继续使用原workspace。

## 配置方向和周推荐

新增研究方向并填写具体研究问题。大方向用于分组，小方向独立评分；核心概念每行一组，用`|`分隔同义或关联表达。组内OR、组间AND用于核心匹配。方法词是加分偏好，排除词须谨慎。

在“设置与定时运行”分别设置每方向核心候选（默认5）和相关候选（默认15）。设置星期、时间和时区后启用每周自动推荐；默认关闭，避免未经配置就联网。程序必须运行，关闭或休眠无法检索；恢复时可以补跑本周已到期且未运行的批次，不追发上周。

## 三个入口

- **下周预览**：最新已保存反馈下的新文献，只读，不评分；不是未来发表论文的预测。
- **重选本周推荐**：初次生成当前周清单，或不满意时换一批。可评分，不自动生成负反馈。
- **评分后加速迭代**：当前所选方向全部论文完成并保存评分后，更新偏好，生成可继续评分的新文献。

详见[三种推荐操作](三种推荐操作.md)。所有已展示论文，包括预览，参与该方向去重；不会重复推送凑数。每周历史保留该周当前推荐，当前可评分清单和最新预览可切换。

## 保存反馈

可逐篇保存，也可点击阅读清单顶部“保存全部反馈”。按钮显示修改篇数，保存当前批次所有修改，包括方向筛选后隐藏的条目。未修改论文不提交；失败条目保留草稿供重试。刷新网页会丢失尚未保存的浏览器草稿，请在切换到新检索前完成保存。

评分、兴趣相关原因和勾选标签参与有限偏好更新；备注保存但不会自动解析为新的研究要求。未读不等于低兴趣。没有有效反馈变化时不会重复叠加学习。预览不可评分，后端也拒绝该批次评分请求。

## 检索与筛选过程

这里显示所有检索候选和统计：来源返回、去重、已展示排除、核心、探索、待核验、筛除，以及实际核心/相关/仅标题推送数。展开后可按分类查看逐篇原因。程序自动扩展检索，不提供“继续检索第几页”按钮；不固定每次200条。标题相关但摘要未取得的论文也能进入相关推送；会尝试从公开主页补摘要，并核对论文身份。

候选不足可能来自已展示去重、概念匹配、来源覆盖、网络或运行边界。结果是已检索候选中的排序，不保证数据库完整召回或全局最优。匹配分不是论文质量分或相关概率。

## 可选功能与备份

可选本地Sentence Transformers见[本地语义增强](本地语义增强.md)。可选Elsevier官方API仅在使用者有获准凭据时补摘要；学校浏览器下载已冻结，当前界面不显示PDF下载。见[PDF功能冻结](PDF功能冻结.md)。

导出菜单保留BibTeX、JSON和Markdown周报。页面底部可下载完整个人数据备份；个人备份含评分，不用于公开分享。分享软件请使用GitHub Releases源码包。首次使用无需ChatGPT账号、订阅或服务器。
