# 本地分组推送与一键下载

在“设置与定时运行”分别设置每个方向的本周核心候选数量（默认5）和相关候选数量（默认15）。旧的总周配额及固定200条候选抓取设置不再影响此模式。两组不互相借用名额；按目标多来源检索、同义表达扩展、邻近问题检索和分页补充。单轮存在时间与分页边界，避免无限运行；来源不足时报告实际数量并提供继续检索，不虚构论文凑数。

核心组优先选择具备摘要且完整覆盖核心概念的论文。相关组包含核心组之外仍高度相关的论文、邻近问题及标题相关但暂缺摘要的论文。仅标题论文标明“相关候选·仅标题”，可读、可评分、可批量下载；相关性判断的证据范围限于标题。缺摘要优先尝试公共主页补取，核对主页DOI或题名，记录摘要来源。网页登录、网络失败或站点限制不会直接导致标题相关条目被丢弃。

“重新检索并迭代”读取最新评分，不占正式周配额，可重复推荐论文；仅最新手动结果显示于下拉框，原始记录与评分保留。每周自动推荐每周保存一次。评分改变偏好，重新检索本身不会训练大模型。

使用“导出→下载论文PDF（ZIP）”批量获取当前清单。程序先尝试已有PDF直链，没有链接时检查论文主页公开PDF端口，必要时尝试配置好的官方接口，再打开对应出版商的机构访问流程。Elsevier使用ScienceDirect当前页面生成的新登录流程，不保存带OAuth状态的临时登录地址；Springer等出版商走各自机构入口。学校选择、密码和验证码由本人在下载浏览器完成，不进入程序配置。机构无法取得时使用独立浏览器上下文进行备用DOI查询。未取得PDF的条目在下载报告中标明，其他论文继续处理；取得的PDF再打包下载。

每篇论文卡片不再展示“导入本地PDF”按钮。下载是否成功取决于链接可用性、个人访问权限和站点响应；一键发起不代表登录及验证码可以无人值守。
