# v2.0.4 验证结果

验证日期：2026年10月14日。本机环境为Linux、Python 3.12。运行要求Python 3.10+，运行时仅使用标准库。

## 本机回归检查

88项测试通过，使用临时目录、合成元数据和模拟外部网络响应；网页接口测试使用本机回环端口。覆盖：

- 评分保存、修改、撤回、同一反馈不重复加权；主题与配置版本隔离。
- 检索词偏好调整、演示隔离、未评分与阅读状态不会被当成负反馈。
- DOI/arXiv版本归并、历史快照与预算保留、正式推送去重。
- 可调高的每周预算、预览不占预算、不改变正式去重或反馈策略。
- 来源解析、缓存、失败说明与来源间候选分配。
- 本机HTTP、异步任务、导出与备份、Host/Origin/令牌校验。
- 公开PDF直链下载、HTML拒绝、大小和超时限制、逐篇失败原因、已有文件复用。
- Fake-IP公网DNS回退、非公网结果拒绝、TLS主机名及固定连接地址。
- 全部失败或本地PDF缺失时不产生空归档，归档原子生成。
- Windows设备保留名和尾点名拒绝、跨平台ISO周计算、进程锁。

## 联网与界面检查

开发阶段的小规模检索已取得Crossref、OpenAlex、arXiv真实候选；未将联网失败替换为合成论文。真实浏览器检查过研究方向、评分原因、标签、备注、预算设置、预览与PDF报告。宽屏和窄屏曾检查布局。

实际网络适配验证中，Fake-IP网络下的出版商域名通过认证的DNS-over-HTTPS解析为真实公网IP；部分开放获取论文已下载并核对首页题名。其他链接返回HTML验证页面或没有PDF直链，均明确报告。此验证不能保证任意出版商链接、机构权限或外部API持续可用。

## 发行与平台范围

源码ZIP按白名单构建，排除运行目录、个人配置、数据库、评分、PDF、截图和凭据。逐文件清单和SHA-256检查通过。wheel内含通用示例与隔离验证用例。

Linux启动与中文空格路径已检查。Windows及macOS提供启动说明和脚本；本机没有这两个系统的实机验收。GitHub Actions配置跨平台回归矩阵，是否通过以仓库实际运行结果为准；添加配置不等于已经完成远端测试。macOS双击启动可能受系统下载文件权限影响，可改用Terminal运行bash脚本。

程序依据摘要与规则推荐，未自动阅读全文或证明研究空白。PDF下载与推荐评分独立。内置周调度默认关闭，必须保持本机服务运行。
