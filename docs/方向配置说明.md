# 方向配置与分类

## 分类原则

按“大方向收纳、小问题独立、交叉问题用词表表达”组织。大方向只帮助导航；真正产生推荐和评分隔离的是稳定 `topic_id`。

例如 HEA_PN 与 HEA_mobility 使用不同问题和方法标准，适合独立方向；同一问题下的温度或材料参数可以先加入词表和问题，不必为每个参数建新目录。机器人与超材料的交叉问题可以归在主要研究对象下，另外把交叉对象写进关键词，不复制两套状态。

如果“研究问题、判断一篇论文好坏的标准、预期阅读产出”明显不同，才新建方向。同一论文在不同方向可以评分不同。大方向不要建立一个同时覆盖所有小方向的巨大检索词表，否则会降低可解释性。

## 最小示例

```json
{
  "topic_id": "robot_tactile_transfer",
  "title": "触觉操作的跨物体迁移",
  "group": "机器人",
  "questions": ["触觉策略如何在新物体上验证泛化？"],
  "keywords": ["tactile manipulation", "robot manipulation"],
  "method_terms": ["sim to real", "imitation learning"],
  "exclude_terms": ["autonomous driving"],
  "stage": "survey",
  "active": true,
  "profile_version": 1
}
```

这些问题由你提出，是检索与阅读目标。程序不会将其当作已确认无人研究的 gap。

## 字段

| 字段 | 类型 | 填写建议 |
|---|---|---|
| `topic_id` | 字符串 | 长期稳定的身份，建议 ASCII 字母、数字、下划线；不要含路径分隔符 |
| `title` | 字符串 | 中文或英文可读名称，可按需调整 |
| `group` | 字符串 | 一个大方向，如 HEA、DDD、医学影像、机器人 |
| `questions` | 字符串数组 | 1–3 个可阅读验证的问题，明确对象与条件 |
| `keywords` | 字符串数组 | 领域常用主题词；英文检索短语通常更有效 |
| `method_terms` | 字符串数组 | 需要的方法、尺度、算法或测试方式 |
| `exclude_terms` | 字符串数组 | 仅排除确实无关含义，避免过宽词 |
| `stage` | 枚举 | `survey`、`gap` 或 `focus` |
| `active` | 布尔值 | `true` 纳入活跃方向；`false` 保留配置但暂停轮次 |
| `profile_version` | 数字字符串／正整数 | 方向配置的科学语义版本；保存时规范为字符串，界面负责维护更新 |

词表以完整项参与匹配及反馈。`Peierls Nabarro` 与 `Peierls-Nabarro` 这类变体可以作为两个短语；新增同义词后试跑，检查匹配是否达预期。不要一次堆入几十个宽泛词。

建议通过网页编辑，使数据库和可移植 profile 同步。手工修改文件前备份、停止服务、核对 JSON 语法，并在重新初始化／加载后检查界面；运行中的数据库不会因为文件被文本编辑器改动而即时同步。

## 阶段如何选择

| 阶段 | 阅读目标 | 配置重点 |
|---|---|---|
| `survey` 综述入门 | 理清术语、主要模型、代表方法 | 少量核心词，适度保留综述 |
| `gap` 候选问题核对 | 比较证据与适用边界 | 写明确待核对条件、方法及反例需求 |
| `focus` 聚焦跟踪 | 跟踪一个已选问题的进展 | 具体对象、机制和方法词，精确排除无关范围 |

阶段改变评分适配项，不自动证明某项研究已达到下一阶段。由你确认阶段转换，必要时更新问题并检查旧评分是否仍适用。不同 profile 版本的偏好贡献按版本隔离，避免旧问题的负反馈影响新问题。

## 总预算与调度

workspace 根目录 `settings.json` 中：

```json
{
  "budget": 10,
  "schedule": {
    "enabled": false,
    "day": 0,
    "time": "09:00",
    "timezone": "Asia/Shanghai"
  }
}
```

`budget` 为正整数的全方向每周总预算。`day` 按 Python 星期顺序：0 周一、1 周二、…、6 周日。`time` 为 24 小时 `HH:MM`。建议通过网页修改，避免手写误差。内置调度依赖本地服务运行，默认不注册任何系统任务。
