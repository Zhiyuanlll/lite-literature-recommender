# 示例方向

这些文件只演示如何填写 profile，未包含个人评分、已荐文章或私人研究材料。
`init --examples` 创建示例后，请先在网页中检查方向与启用状态，再开始真实检索。
普通 `init` 保持方向为空，首次使用者自行创建方向。

| 示例 | 大方向 | 适合观察的配置区别 |
|---|---|---|
| HEA_PN | HEA | 位错芯、Peierls–Nabarro、广义层错能 |
| DDD_junction | DDD | 位错交结、三维离散位错动力学 |
| medical_imaging | 医学影像 | 外部验证、域偏移、分割方法 |
| robot_embodied | 机器人 | 操作任务、仿真到真实迁移、触觉 |

选择自己研究领域的词。示例中的问题是研究者提出的待核对问题，不是程序发现的
研究空白，也不是该领域文献综述。医学示例用于论文检索，不用于临床决策。

导入示例最方便的方式是 `python -m lite_recommender init --examples`。
也可以在网页“新增方向”中按样例填表。JSON 文件名仅方便阅读；真正身份是
`topic_id`，因此不要通过改文件名来改身份。完整字段说明见
[方向配置说明](../docs/方向配置说明.md)。
